## 1. 목적

40문항 중 원하는 것을 찾고, 어디까지 읽었는지와 무엇이 헷갈리는지 행마다 본다. 별도 복습 화면이 없으므로 `헷갈림만` 이 복습 입구다(2026-11-14 결정).

## 2. 사용자가 하는 일

1. 장 이동 줄로 과목을 바꿔 질문을 고른다
2. `빈출 20` 으로 걸러 별 많은 질문부터 고른다
3. `헷갈림만` 으로 걸러 헷갈린 질문만 다시 읽는다
4. 질문을 읽고 뒤로 오면 보던 자리로 돌아온다

## 4. 부품

| 부품 | 배치 | 모양 |
|---|---|---|
| 머리 | H-main | 목차 켜짐 |
| 분할 선택 | 머리 아래, 위 8 아래 8, 좌우 20 | 분할 선택(00 5.7). `전체 40` `빈출 20` `헷갈림만 3`. 헷갈림 0 이면 `헷갈림만`. 붙지 않는다. 칸 폭 균등, 조각 고정 폭(00 5.7) |
| 장 이동 줄 | 분할 선택 아래, 붙음(접힌 머리 바로 아래) | 높이 44, 흰 바탕, 아래 1px `--line`. 과목 4개 글 버튼 `ui`, 사이 16, 왼쪽 20. 지금 장 `--ink` + 2px 밑줄, 나머지 `--ink-2`. 칸 하나의 영역 44. `전체` 보기에서만 있다 |
| 장 머리 | 위 24 아래 12, 좌우 20 | 1줄: 기호 `sym-<과목>` 48 + 사이 12 + 이름 `title-2` + 오른쪽 `읽음 10 / 12` `label` `--ink-3`. 이름 아래 4 에 헷갈림 꼬리표(있을 때). 2줄(위 12): 블록 줄, 블록 `flex: 1` 최대 24 |
| 주제 머리 | 위 20 아래 4, 좌우 20 | `label` `--ink-3` `Array & Linked List · 4` |
| 질문 행 | | 목록 행(00 5.8). 메타: 빈출 꼬리표, 헷갈림 꼬리표, `꼬리질문 N`(0 이면 없음). 빈출·헷갈림만에서는 메타 앞에 과목 이름. 빈출 20 에서는 별 꼬리표를 뺀다(무리 머리에 있음) |
| 읽던 행 | | 목록 행의 읽던 행 모양. 누르면 이어 읽기(00 7.2) |
| 장 사이 | | 띠 8 |
| 별 무리 머리 (빈출) | 위 24 아래 4, 좌우 20 | 빈출 꼬리표 + `3문항` `label` `--ink-3` |
| 끝 안내 (빈출) | 위 24 아래 40, 가운데 | `ui` `--ink-2` + 글 버튼 `전체 보기` |
| 헷갈림 요약 | 위 24 아래 16, 좌우 20 | `3` `display` `--ink` + `문항` `label`, 아래 4 안내 `ui` `--ink-2`, 아래 16 주 버튼 L |

- 붙는 높이: 접힌 H-main 48 + 장 이동 줄 44 = 92(00 3.4). 빈출·헷갈림만 보기는 목록이 짧아(20, N) 장 이동 줄 없이 48.
- 지금 장: 장 머리를 IntersectionObserver(읽기 선, 00 9.2-6)로 보고 정한다. 스크롤 이벤트 없음.
- 장 이동: 누르면 그 장 머리가 장 이동 줄 바로 아래 오게 `scrollIntoView`, 주소는 `#/toc/<과목>` 으로 `replaceState`. 화면 읽기에는 장 머리로 초점.
- 360 폭: 장 이동 줄 글 4개 = 약 250 + 사이 48 + 왼쪽 20 = 318 이라 한 줄(실측 00 8.1).

순서
- 전체: 책 순서(과목 > 주제 > 질문).
- 빈출 20: 별 4, 2, 1 무리, 무리 안은 책 순서. 읽음 여부로 순서를 바꾸지 않는다(읽는 동안 줄이 움직이지 않게).
- 헷갈림만: 책 순서. 헷갈림 꼬리표는 모든 행이 같으므로 뺀다.

## 5. 상태

| 상태 | 모양 |
|---|---|
| 전체 맨 위 | 위 그대로. 읽던 행 하나가 `--stage` 바탕 |
| 장 이동 뒤 | 장 이동 줄 밑줄이 그 장, 장 머리가 줄 바로 아래 |
| 첫 실행 | 글리프 모두 안 읽음, 블록 줄 모두 `--line`, 읽던 행 없음, `헷갈림만`(숫자 없음) |
| 헷갈림만 0개 | 06 2.1 |
| 홈 탑에서 옴(`#/toc/<과목>`) | 전체 보기, 그 장 머리가 장 이동 줄 아래. 초점은 그 장의 첫 안 읽은 행(덜 쌓인 과목을 누른 뜻과 이어짐) |
| 질문에서 뒤로 옴 | 떠날 때의 보기와 스크롤. 이전/다음으로 질문이 바뀌었으면 지금 질문 행이 보이게. 상태가 바뀐 행의 글리프만 pop. 헷갈림만에서 표시를 끈 행은 `fade` 로 빠짐 |

## 6. 누르기와 움직임 (00 9절 토큰)

| 무엇 | 어떻게 | 토큰 |
|---|---|---|
| 분할 선택 바꿈 | 흰 조각 이동. 지금 목록 opacity 0, 새 목록 첫 8행 `translateY(8px) → 0` + opacity. 스크롤은 분할 선택이 머리 아래 오게 | base, fade + base + stagger |
| 장 이동 | 부드러운 스크롤(움직임 줄이기면 바로), 밑줄 이동 | base |
| 행 누름 | 바탕 `--band` | micro |
| 질문에서 뒤로 옴 | 상태가 바뀐 행의 글리프와 블록 `scale(.5) → 1` | pop |
| 요약 버튼 | | press |

움직임 줄이기: 조각과 밑줄은 바로 이동, 목록은 `fade` 만, 글리프는 바로 바뀜.
