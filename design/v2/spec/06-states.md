## 1. 첫 실행

스플래시와 온보딩 장은 두지 않는다(로그인·목표·알림이 없어 받을 입력이 없다. 1회차 결정 유지). 설명은 그 기능을 처음 쓰는 자리에서 한 번만.

| 언제 | 어디 | 무엇 | 다시 보이나 (`seen` 키) |
|---|---|---|---|
| 앱을 처음 염 | 홈 | 1.1 첫 실행 홈 | 질문 하나를 읽기 시작하면 평소 홈 |
| 질문을 처음 염 | 질문 떠올리기 판 | 1.2 판 안내 문장 | 답 보기를 한 번 누르면 끝(`recallTip`) |
| 헷갈려요를 처음 켬 | 질문 | 알림 한 줄 `목차의 헷갈림만에서 모아 볼 수 있어요` | 한 번(`confToast`) |
| 질문을 처음 다 읽음 | 질문 끝 영역 | `홈의 과목 진도에도 쌓여요` | 한 번(`firstRead`) |
| 오프라인 저장이 처음 끝남 | 아무 화면 | 알림 한 줄 `이제 인터넷 없이도 볼 수 있어요` | 한 번(`offlineDone`) |

### 1.1 첫 실행 홈

```
       | [마크] CS 차곡                              |
       | 홈    목차    시뮬레이션                     |
       |  +--------------------------------------+  |
       |  | [그림 띠: 자료구조 장면]                |  |
       |  | 자료구조 · Array & Linked List          |  |
       |  | Array는 어떤 자료구조인가요?             |  |  제목만 (발췌 없음)
       |  | [__][__][__][__][__]  처음부터 5단락     |  |
       |  | [            첫 질문 읽기          ]    |  |  주 버튼 L
       |  +--------------------------------------+  |
       |  랜덤 질문 (평소와 같음)                      |
       |  과목 진도                          0 / 40  |
       |   __  __  __  __  (빈 탑 4개, 흰 빈 칸 + 1px --line)    |
       |   자료구조 운영체제 데이터베이스 네트워크       |
       |   질문을 다 읽을 때마다 여기에 한 칸씩 쌓여요   |  ui --ink-2 (범례 대신)
       |  자주 나온 질문, 시뮬레이션, 이 기기 (평소와 같음) |
```
- 첫 질문은 책 순서 첫 문항, 책 순서 맥락(00 7.2 `홈 다음 질문, 첫 질문 읽기`).
- 움직임: 없음(쌓인 블록이 없으므로 탑 쌓기도 없다).

### 1.2 질문을 처음 염

떠올리기 판의 안내 문장만 `답은 가려 뒀어요. 핵심을 한두 문장으로 떠올린 뒤 열어 보세요.` 로 바뀐다(03 5.2). 따로 상자를 두지 않는다.

## 2. 빈 상태

### 2.1 목차 헷갈림만 0개

```
       | ( 전체 40 | 빈출 20 | [헷갈림만] )           |
       |              [그림 160x120]                  |  ill-empty-conf
       |           헷갈리는 질문이 없어요               |  title-2 가운데
       |     읽다가 헷갈리면 질문 아래 헷갈려요를        |  ui --ink-2 가운데
       |              눌러 두세요                      |
       |            [ 빈출 20 보기 ]                   |  보조 버튼 M, 폭 글자 + 40
```
- 좌우 20. 위 56, 그림과 제목 사이 20, 제목과 설명 사이 8, 설명과 버튼 사이 24.
- 한 번이라도 표시했다가 모두 끈 경우(`everConf`): 제목 `헷갈림을 모두 풀었어요`, 설명 `다시 볼 질문이 생기면 여기에 모여요`.
- 남색 버튼을 쓰지 않는다. 할 일이 없는 화면이라 다음 길만 조용히 연다.
- 그림 `ill-empty-conf` 는 쌓인 카드 + 체크다. 원통이 아니라 데이터베이스 기호 `sym-db` 와 실루엣이 다르다(illustrations.md 4.3).

### 2.2 다른 빈 자리

홈은 첫 실행 말고 빈 섹션이 없다(빈출 20, 시뮬레이션 30, 랜덤은 늘 뽑힘). 시뮬레이션 목록은 빈 상태가 없다. 관련 질문이 없는 시뮬레이션은 없다(30개 모두 연결).

## 3. 불러오기와 오류

### 3.1 본문 불러오는 중

본문 데이터(`data/notes.json`, 약 140KB)를 처음 받는 동안(오프라인 저장 뒤에는 거의 바로 끝남).
- 머리(H-main)는 바로 그린다. 그 아래는 자리 모양만: 히어로 카드 자리(그림 띠 `--stage`, 과목·제목·버튼 자리에 `--band` 막대, 모서리 6, 버튼 자리는 버튼과 같은 14), 띠, 섹션 머리 막대와 카드 자리. 움직이지 않는다(반짝임 없음). 회전 표시는 쓰지 않는다.
- 이 자리 모양은 불러오는 동안에만 쓴다. 답 가림 판에는 쓰지 않는다(00 7.5, 1회차 지적: 가짜 막대).
- 400ms 안에 끝나면 자리 모양 없이 바로 화면(깜빡임 방지).
- 질문 화면: H-sub(과목 이름 없음) + 빈 진행 칸, 제목 막대 둘 + 정보 줄 `--band` 면만. 판 자리는 비운다(큰 회색 판을 그리지 않는다: 답 가림 때의 떠올리기 판과 같은 실루엣이 되지 않게, 03 6절). 캔버스 qLoading.
- 시뮬레이션 목록: 장 이동 줄, 장 머리, 포스터 칸 `--stage` 와 이름 자리 `--band` 면. 캔버스 simsLoading.
- 탑과 블록 모양은 불러오는 중에 쓰지 않는다(첫 실행 빈 탑과 헷갈리지 않게).

### 3.2 본문을 못 불러옴 (오류 또는 10초 넘김)

```
       | [마크] CS 차곡                              |
       |              [그림 160x120]                  |  ill-notfound (오프라인이면 ill-offline)
       |           내용을 불러오지 못했어요             |  title-2
       |     인터넷 연결을 확인하고 다시 시도해 주세요    |  ui --ink-2
       |  [               다시 시도               ]   |  주 버튼 L
```
- 오프라인이면(`navigator.onLine === false`) 설명이 `인터넷에 연결되면 처음 한 번 내용을 받아 와요`. 그림도 이때만 구름 `ill-offline` 이다(구름 + 아래 화살표가 내려받기로 읽혀, 온라인 실패에는 쓰지 않는다).
- 질문 주소로 바로 들어왔는데 본문을 못 받음: H-sub(과목 이름 없음, 켜진 탭 목차) + 그림 `ill-notfound`(구름 `ill-offline` 은 쓰지 않는다) + 질문을 불러오지 못했어요 + 같은 설명 + 다시 시도. 캔버스 qFail.

### 3.3 없는 주소 (`#/q/<없는 id>`, `#/sim/<없는 id>`)

```
       | <                         홈  목차  시뮬레이션 |  H-sub (과목 이름 없음)
       |              [그림 160x120]                  |  ill-notfound
       |            찾는 질문이 없어요                  |  title-2
       |          주소가 바뀌었을 수 있어요              |  ui --ink-2
       |  [                목차로                 ]    |  주 버튼 L
```
- 시뮬레이션이면 `찾는 시뮬레이션이 없어요`, 버튼 `시뮬레이션 목록으로`.
- 그림 `ill-notfound`(문서 + 돋보기)는 3.2 의 못 불러옴과 같은 그림이다.

### 3.4 진도 저장

| 경우 | 무엇 |
|---|---|
| 쓰기 실패(사파리 개인 정보 보호, 공간 없음) | 홈 머리 아래 안내 줄 `이 브라우저에서는 진도가 저장되지 않아요. 앱을 닫으면 처음 상태로 돌아가요.` + 닫기. 이번 실행 동안 다시 안 보임. 메모리로 동작 |
| 옛 형식(v 없음) | 조용히 옮긴다(00 6.5). 알림 없음 |
| 모르는 id | 그 id 만 버린다. 알림 없음 |
| 읽을 수 없는 값 | 원본을 `cs-chagok-bak` 에 남기고 빈 상태로. 홈 머리 아래 안내 줄 한 번 `저장된 진도를 읽지 못해 새로 시작했어요.` |

### 3.5 시뮬레이션 불러오기

- 무대 자리에 `--stage` 판(모서리 24, 높이 = 그 시뮬레이션 도식 비율)을 먼저 그린다. 400ms 안에 뜨지 않으면 판 가운데 `ui` `--ink-2` `시뮬레이션을 불러오는 중`. 뜨면 opacity `micro` 로 바뀐다.
- 못 불러옴(오류 이벤트 또는 8초):
```
       |  +----------------------------------------+  |  무대 자리 --stage
       |  |       시뮬레이션을 열지 못했어요          |  |  row 가운데
       |  |   인터넷 연결을 확인하고 다시 시도해 주세요 |  |  ui --ink-2
       |  |   [ 다시 시도 ]       그림으로 보기       |  |  보조 버튼 M + 글 버튼
       |  +----------------------------------------+  |
```
- 오프라인이고 이 시뮬레이션이 아직 저장되지 않았으면 설명이 `오프라인 저장이 끝나기 전이라 아직 열 수 없어요`.
- 그림으로 보기: 같은 시뮬레이션의 A안 도식(머리표 줄 자름, 03 5.4)을 무대 안에 정지 그림으로. 하단 막대는 단계 줄 없이 `글로 읽기` 하나(주).

## 4. 진도 초기화

입구: 홈 `이 기기` 의 `진도 초기화` 행(01 4.7). 진도가 0 이면 꺼짐.

```
       |  (가림막 --ink 40%)                           |
       |  +----------------------------------------+  |  시트 (00 5.13)
       |  | 진도를 처음부터 다시 할까요?              |  |  title-2
       |  | 읽음 17문항, 헷갈림 3문항, 이어 읽기 위치가 |  |  ui --ink-2
       |  | 모두 지워져요.                           |  |
       |  | [   취소   ]  [      초기화      ]      |  |  보조 M · 지우기 M
       |  +----------------------------------------+  |
```
- 시트에 손잡이를 두지 않는다(밀어 닫기 없음). 가림막 누름, 취소, Esc 로 닫힌다.
- 초기화를 누르면: 시트 닫힘, `read`, `conf`, `prog`, `last`, `everConf` 를 지운다(`seen` 은 남김: 안내를 다시 보이지 않게). 지우기 전 값을 메모리에 둔다.
- 알림 한 줄 `진도를 초기화했어요` + 동작 `되돌리기`. 10초 또는 홈을 떠날 때까지 남고, 알림을 누르고 있거나 초점이 있는 동안 시간이 멈춘다. 되돌리기를 누르면 그대로 복구. 시간이 다 되거나 홈을 떠나면 버린다.
- 홈은 바로 첫 실행 홈 모양(1.1)이 된다. 탑은 움직이지 않고 비워진다(`fade`).
- 알림 자리: 홈은 하단 막대가 없어 머리 아래 12 에 뜬다(00 5.11). 방금 바뀐 읽음 숫자와 탑을 덮지 않고, 위에서 8 내려오며 들어온다.

## 5. 오프라인 (서비스 워커)

저장 대상(약 1MB): 앱 틀(HTML, CSS, JS), `data/notes.json`, 글꼴(Pretendard 부분집합), 본문 도식 SVG 31개, 시뮬레이션 30개(kit 포함), 일러스트, 브랜드 아이콘. 저장 순서: 앱 틀 → 본문 → 글꼴 → 도식 → 시뮬레이션(본문을 먼저 볼 수 있게).

| 상태 | 어디에 | 무엇 |
|---|---|---|
| 저장하는 중 | 홈 `이 기기` 오프라인 행 | `저장하는 중 64%` (`--ink-3`). 다른 화면에는 아무 표시 없음 |
| 저장 끝 | 오프라인 행 `저장됨`(체크). 처음 한 번 알림 한 줄 `이제 인터넷 없이도 볼 수 있어요` | |
| 저장 실패(공간 부족 등) | 오프라인 행 `저장하지 못했어요` + 글 버튼 `다시 시도` | |
| 지금 오프라인, 저장 끝 | 모든 화면 머리 아래 안내 줄(`--band`, 닫기 없음) `오프라인이에요. 저장된 내용으로 보고 있어요.` 연결되면 사라짐(`fade`) | |
| 지금 오프라인, 저장 전 | 같은 안내 줄 `오프라인이에요. 저장이 끝난 내용만 볼 수 있어요.` 저장 안 된 시뮬레이션은 3.5 | |
| 새 판이 있음 | 알림 한 줄 `새 내용이 있어요` + 동작 `새로 고침`(5초, 누르지 않으면 다음 실행 때 바뀜). 진도는 그대로(00 6.5 옮기기) | |
| 처음 방문이 오프라인 | 서비스 워커가 없어 브라우저 오류 화면. 앱이 다룰 수 없다 | |

## 6. 움직임 요약

| 상태 | 움직임 |
|---|---|
| 안내 줄 나타남 / 사라짐 | opacity `base` / `fade`. 자리는 바로 잡고 닫힘 |
| 알림 한 줄 | 막대 위 자리는 `translateY(8px) → 0`, 머리 아래 자리는 `translateY(-8px) → 0`, 둘 다 opacity 와 함께 `base`. 사라짐 `fade` |
