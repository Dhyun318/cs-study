CS 차곡 화면 흐름

썸네일을 누르면 왼쪽 폰이 그 화면으로 이동해요.

  • CS 차곡은 CS 전공면접 기출 책을 휴대폰으로 공부하는 개인 공부 앱이에요. 면접 연습 앱이 아니라서 면접관·응시·채점 연출은 없어요
  • 기능은 docs/features.md 의 1차만 넣었어요. 검색·북마크·모의면접 모음·글자 크기·다크 모드는 나중, 공부 알림은 뺐어요
  • 서버와 로그인 없이 프론트만 만들어요. 읽음·헷갈림·마지막 위치는 기기 안 localStorage 에 저장해요(이 프로토타입도 실제로 저장, 처음엔 예시 진도)
  • 앱은 버셀에 공개 배포해서 책 문장·그림·예시 값은 넣지 않아요. 본문은 notes/ 의 우리 말 해설, 정지 그림은 illustrations/ 의 새 일러스트(지금은 A안 정돈된 도식)
  • 움직이는 설명은 시뮬레이션이에요. 책 그림 31개를 30개 화면으로 만들어요(Hash 저장과 충돌은 하나). 완성된 것은 sims/<id> 페이지를 폰 안에 그대로 띄우고, 아직인 것은 같은 틀에 제작 중으로 보여요(완성 여부는 make-data.py 를 다시 돌리면 갱신)
  • 질문 상세는 답을 가린 채 열려요. 먼저 떠올려 본 뒤 답 보기, 꼬리질문은 눌러서 펼치기, 헷갈림·이전·다음은 아래 막대에 둬요
  • 홈의 이어 읽기는 마지막으로 본 질문과 멈춘 단락을 기억해요. 링은 그 질문을 읽은 비율이에요
  • 복습은 헷갈림 표시한 질문만 한 장씩 봐요. 이제 알아요는 목록에서 빼고, 아직 헷갈려요는 다음에 다시 나와요
  • 별은 기출 빈도 표시로만 써요. 주황 바탕 꼬리표에 진한 글자(흰 바탕 위 주황 글자는 대비가 모자라서 안 써요)
  • 홈은 최종 시안 P 그대로예요(O 목록형 + N 이어 읽기 카드). 오른쪽 위 … × 자리는 호스트 앱 몫이고, 뒤로 화살표는 하위 화면에만 둬요
  • 바탕은 흰색·회색 면, 글자 파랑 #0E5CF4, 남색 버튼 #03257B, 글꼴 Pretendard. 오픽 앱 토큰 그대로, 라이트 테마만
  • 아이콘은 P와 같은 TDS mono(별, 화살표) + Tabler outline 한 세트예요
  • 390px 기준으로 만들고 360px 까지 넘침 없이 보여요. 누르는 곳은 44px 이상. 주소 끝에 ?only=1 이면 폰만(휴대폰에서 열 때), ?s=화면 id 로 시작 화면을 골라요
