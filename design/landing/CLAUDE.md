# design/landing/ 랜딩 시안

사이트 첫 주소(/)에 둘 랜딩 페이지 시안. 앱은 /app/. 파일 하나(`index.html`, CSS·JS 포함, 의존성 없음).

## 결정 (2026-11-14)
- 넓은 화면 모션은 폰 프레임 안에서 실제 앱 화면이 움직이는 소개다. 추상 CS 모션, 스플래시는 쓰지 않는다(식상함, 사용자 결정).
- 넓은 화면 장면 5개: 답 가림 펼침, 읽은 만큼 진행 칸, 홈 탑 블록 쌓기, TCP 3-way 시뮬레이션, 헷갈려요 표시 후 목차 헷갈림만 거르기.
- 넓은 화면(960 이상): 폰이 오른쪽에 붙고 왼쪽 설명을 스크롤하면 장면이 바뀐다(IntersectionObserver, 스크롤 리스너 없음).
- 좁은 화면(959 이하): 오픽 앱 온보딩처럼 한 장씩 가로로 넘기는 소개 4장(사용자 결정, 휴대폰에서는 휘리릭 넘어가는 쪽이 더 잘 먹힌다). 예전의 폰 자동 재생은 버렸다. 스크롤 소개, 과목 소개, 끝 섹션, 바닥글은 좁은 화면에서 숨긴다.
  - 장 구성: 위 사진(약 58%) + 사진 위에 뜬 앱 부품 조각 하나, 아래 제목(핵심어만 파랑) + 한 줄 설명, 점 4개, 건너뛰기, 남색 다음 버튼. 1장 답 가리고 먼저 떠올리기, 2장 시뮬레이션(TCP SYN 한 단계), 3장 진도 탑 블록 +1, 4장 헷갈림만 3.
  - 1장 제목 위에 서비스 한 줄 소개(h1). 제목 위 여백 안에 띄워 네 장의 사진 높이와 제목 자리를 같게 했다.
  - 넘기기: CSS scroll-snap 가로 스와이프, 다음 버튼, 점 누르기. 자동 넘김 없음. 지금 장은 트랙 기준 IntersectionObserver(60% 이상 보이는 장). 마지막 장은 다음 대신 시작하기(./app/), 건너뛰기는 자리만 남기고 숨김.
  - 조각은 장이 켜질 때 짧게 한 번 움직이고(앱 토큰 fade 120, base 240, pop 240), 완전히 벗어난 장은 처음 상태로 돌려 다시 들어오면 또 움직인다.
  - 사진: `photos/photo-1~4.webp`(코덱스 AI 사진, 설명은 `photos/README.md`, 이 폴더는 코덱스 것이라 고치지 않는다). onload 로 서서히 보이고, 불러오는 동안은 연한 판, 없거나 실패하면 앱 일러스트(`../v2/illustrations/hero-db, hero-net, hero-done, ill-empty-conf`).
  - 조각 자리는 사진마다 얼굴, 손, 화면을 피한다: 1 오른쪽 아래(의자), 2 아래(공책 아래쪽, 노트북 화면 피함), 3 오른쪽 위(창), 4 위(창, 휴대폰과 손 피함). 사진 맞춤 기준점도 그에 맞춰 2는 아래, 3·4는 위.
- 움직임 줄이기: 넓은 화면은 장면 끝 상태 그림. 좁은 화면은 네 조각 모두 처음부터 끝 상태, 넘김도 즉시 이동.
- 폰 안 화면은 `../v2/index.html` 부품 CSS 를 옮겨 정적 HTML 로 그리고 통째로 줄인다(데이터 로딩 없음). 시뮬레이션도 iframe 이 아닌 정적 사본(문구는 `sims/tcp-handshake` 와 같음). 좁은 화면 조각도 같은 부품 CSS(분할 버튼, 블록, 글리프, 버튼)를 실제 크기로 쓴다.
- 폰 안 움직임 시간은 앱 토큰(spec/00 9절) 그대로. 단 탑 블록 쌓기 간격만 24ms 대신 60ms(폰이 줄어 있어 24ms 면 안 보임). 랜딩 등장은 references-rea.md 의 dur-enter 420ms, dur-hero 800ms.
- 공부 기록(localStorage `cs-chagok`)이 있어도 자동으로 넘기지 않고, 시작하기 버튼 글만 `이어서 공부하기`로 바꾼다(좁은 화면은 마지막 장 버튼). 2026-11-14 사용자 결정: 다시 온 사람도 랜딩을 볼 수 있게.
- 문구에 쓰지 않는 것: 로그인, 동기화, 알림, 검색, 면접 연출. 교재·출판사 이름.

## 검사와 증거
- `verify.py`: 390·360·1440 가로 넘침(넘기는 장 안쪽은 그 장 폭 기준), 콘솔 오류, 누르는 영역 44, dash·큰따옴표. 좁은 화면은 첫 화면에 다음 버튼, 세로 스크롤 없음, 사진 4장, 자동 넘김 없음, 다음·스와이프·점·건너뛰기, 마지막 장 시작하기, 움직임 줄이기 끝 상태, 사진 실패 시 일러스트, 기록 있으면 이어서 공부하기. 장 스크린샷을 `shots/<폭>/` 에 다시 찍는다(390 은 `rm-`, `fb-` 도).
- `motion/record.py`: `scroll-1440.mp4`(스크롤 10초). `auto-390.mp4` 는 버린 자동 재생 방식 영상이라 지금 화면과 다르다.
- 둘 다 프로젝트 루트에서 `python3 -m http.server 8791 --bind 127.0.0.1` 을 띄운 뒤 실행한다.
