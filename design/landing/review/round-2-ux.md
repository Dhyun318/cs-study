## 필수 수정 (이것만 고치면 90 이상)

1. **휴대폰 기능 5개 앞에 묶음 제목 하나.** `index.html` 의 `<ol class="lp-steps">` 바로 위(`.lp-pin` 다음)에 `<h2 class="lp-h2 lp-steps-h">이렇게 공부해요</h2>` 를 넣고, 휴대폰은 `.lp-steps-h { padding: 72px 20px 0 }`, `.lp-steps { padding-top: 32px }`, 넓은 화면(960 이상)은 `.lp-steps-h { display: none }`(넓은 화면 grid 자리에 안 끼게). 첫 화면 끝 한 줄과 걸음 1 제목 사이에 경계가 생겨, 같은 다섯 제목이 데모 다음 자세히 보기로 읽힌다. 기대 효과: 정보 구조 +1.5, 위계 +0.5.
2. **걸음 2 조각에서 눌리지 않는 이어 읽기 버튼 빼기.** `.lp-step:nth-child(2) .lp-frag` 안의 `<span class="btn l pri">이어 읽기</span>` 한 줄 삭제. 이 걸음의 요점은 진행 칸과 `6단락 중 3번째` 라 버튼이 없어도 뜻이 산다. 걸음 1 답 보기만 남색 버튼으로 남아 남색 = 누르면 된다는 규칙이 맞아지고, 하단 고정 시작하기와 같은 모양 두 개가 한 화면에 보이던 것도 없어진다(다른 조각 3·4·5 에는 남색 버튼이 없음). 기대 효과: 모션·인터랙션 +0.5, 위계 +0.5, 문구 +0.5.
3. **폭 316px 미만에서 멈춤 버튼 넘침 고치기.** `@media (max-width: 315.98px) { .lp-ctl { display: flex; justify-content: center; } .lp-pause { position: static; } .lp-dots button { width: 40px; } }`. 점 5개(40) + 멈춤(44) = 244px 라 사파리 150%(390 은 260, 375 는 250)까지 들어간다. 높이 44 는 그대로라 누르는 영역도 유지. 기대 효과: 접근성 +1.

세 가지 합 약 +5, 예상 약 91. 점수와 별개로 작업 트리를 배포해야 공유 미리보기(og 태그) 고침이 실제 사용자에게 닿는다.
