# 기출 모의면접 문항

## 모의면접 1

1. 1분 정도 분량으로 자기 소개를 부탁드립니다.
   - 개발자의 길을 택하게 된 계기가 궁금합니다.
   - 개발 지식은 평소 어떤 식으로 익히시나요?
   - 여러 지원자 중에서 왜 우리 회사가 당신을 뽑아야 하는지 말씀해 주실 수 있나요?

2. 해시 테이블이 무엇인지 설명해 주실 수 있나요?
   - 서로 다른 키가 같은 해시 값을 가져 충돌하면 어떻게 처리하나요?
   - 개방 주소법으로 충돌을 해결한다고 하셨는데, 이 방식에서 원소를 지울 때 어떤 문제가 생길까요?
   - 이중 해싱이 무엇인지 설명해 주실 수 있나요?

3. HTTP의 GET과 POST는 어떤 점이 다른가요?
   - PATCH와 PUT은 어떻게 다른가요?

4. 삽입 정렬을 설명해 주세요.
   - 정렬 알고리즘 중 가장 빠른 것은 무엇인가요?
   - 퀵 정렬을 설명해 주세요.
   - 선택 정렬을 설명해 주세요.

5. DB에서 쓰는 트랜잭션을 간단히 설명해 주시겠어요?
   - 트랜잭션이 데이터 무결성을 지키기 위해 갖춘 성질에는 무엇이 있나요?
   - 데드락이 무엇인지 간단히 설명해 주세요.
   - 데드락은 어떤 방법으로 풀 수 있나요?

6. 지원자님께서 저희에게 물어볼 것이나 덧붙이고 싶은 말이 있다면 간단히 말씀해 주세요.

## 모의면접 2

1. 1분 정도 자기 소개를 부탁드립니다.
   - 혼자서는 감당하기 어려운 난도 높은 과제를 맡게 된다면 어떻게 대응하시겠어요?
   - 팀 프로젝트에서 주로 맡았던 역할은 무엇인가요? 관리자 역할이나 팀원 간 갈등을 조율한 경험이 있다면 들려주세요.
   - 팀을 꾸릴 때 처음에 마음에 들었던 팀원과 함께 일하며 사이가 멀어진 적이 있나요? 반대로 처음에는 별로였는데 같이 일할수록 좋아진 경우가 있었나요?

2. 멀티 스레드와 멀티 프로세스를 비교해서 설명해 주세요.
   - 여러 프로세스나 스레드가 동시에 자원에 접근할 때 생기는 동기화 문제를 알고 계신가요?
   - 그런 동기화 문제는 어떻게 해결하는 것이 좋을까요?
   - 뮤텍스와 세마포어의 차이를 중심으로 설명해 주세요.

3. 힙 자료구조에 대해 아시나요?
   - 힙을 구현할 때 배열과 연결 리스트 중 어떤 것을 쓰는 것이 좋을까요?
   - 힙의 push 연산과 pop 연산의 시간 복잡도는 각각 얼마인가요?
   - pop을 하면 루트 노드가 빠지는데, 그 다음에는 어떤 동작이 이어지나요?

4. 이진 탐색 트리에 값이 1000개 저장되어 있다면 탐색은 몇 번 정도 필요할까요?
   - 탐색 시간 복잡도를 O(log N)으로 보신 것 같은데, 최악의 경우에는 어떻게 되나요?
   - 어떤 상황에서 탐색 시간 복잡도가 O(N)이 되나요?
   - 이 문제를 해결할 방법을 알고 계신 것이 있나요?

5. 관계형 DB에서 인덱스는 왜 필요한가요?
   - 인덱스를 쓰면 검색이 빨라진다고 하셨는데, 그렇다면 모든 컬럼에 인덱스를 만드는 것이 좋을까요? 어떻게 생각하세요?
   - 어떤 컬럼의 값이 한쪽에 거의 몰려 있다면(예를 들어 전체의 대부분이 같은 값인 경우) 인덱스를 만드는 것이 좋을까요?
   - MySQL에서 인덱스 자료구조로 주로 쓰는 B+ 트리의 검색 시간 복잡도는 어떻게 되나요?
   - 해시 인덱스는 검색이 O(1)인데, 그럼 왜 B+ 트리를 사용하는 걸까요?

6. 지원자님께서 저희에게 물어볼 것이나 덧붙이고 싶은 말이 있다면 간단히 말씀해 주세요.

## 모의면접 3

1. 3분 정도 시간을 드릴 테니 편하게 자기 소개를 해 주세요.
   - 백엔드(또는 지원하신 다른 직무)를 선택하신 이유는 무엇인가요?
   - 백엔드(또는 다른 직무)로 지원하셨는데, 다른 역할을 맡게 되어도 입사할 의향이 있으신가요?
   - 본인의 성격에서 장점과 단점을 말씀해 주세요.

2. 연결 리스트를 간단히 설명해 주세요.
   - 연결 리스트와 배열을 비교해서 설명해 주세요.
   - 어떤 상황에서는 배열보다 연결 리스트를 쓰는 편이 좋을까요?
   - 동적 배열을 간단히 설명해 주세요.

3. 웹 서비스의 REST API가 갖춰야 할 특성을 떠오르는 대로 말씀해 주시겠어요?
   - REST API가 그런 특성을 갖춰야 하는 이유와 장점은 무엇인가요?
   - 그렇다면 모든 웹 API를 RESTful하게 만드는 것이 좋을까요?

4. 가상 메모리를 간단히 설명해 주세요.
   - 페이지 방식과 세그멘테이션 방식을 간단히 비교해 주세요.
   - 알고 계신 페이지 교체 알고리즘에는 어떤 것이 있나요?
   - LRU 알고리즘과 LFU 알고리즘을 간단히 비교해 주세요.

5. NoSQL을 프로젝트에서 사용해 보신 적이 있으신가요?
   - NoSQL의 장점은 무엇인가요?
   - RDB의 장점은 무엇인가요?

6. 지원자님께서 저희에게 물어볼 것이나 덧붙이고 싶은 말이 있다면 간단히 말씀해 주세요.

## 모의면접 4

1. 1분 정도 자기 소개를 부탁드립니다.
   - 개발을 언제부터 시작하셨나요? 공부를 시작하게 된 계기가 있었나요?
   - 본인만의 개발 공부 방법이 있으신가요?
   - 컴퓨터 공부를 하며 어려웠던 점이 있었나요? 있었다면 어떻게 극복하셨나요?
   - 본인만의 스트레스 해소법이 있으신가요?

2. 해시 테이블의 검색 시간 복잡도는 어떻게 되나요?
   - 최악의 경우 O(N)이라고 하셨는데, 조금 더 자세히 설명해 주시겠어요?
   - 해시 값이 충돌했을 때는 어떻게 해결해야 할까요?
   - 분리 연결법(separate chaining)을 자세히 설명해 주세요.

3. RDB에서 쓰이는 JOIN의 종류를 아는 대로 말씀해 주세요.
   - inner join은 어떤 조인인가요?
   - left join은 어떤 조인인가요?

4. 브라우저 주소창에 www.google.com을 입력했을 때 화면이 뜨기까지의 과정을 설명해 주세요.

5. TCP와 UDP를 비교해서 설명해 주세요.

6. 쿠키와 세션을 비교해서 설명해 주세요.

7. 지원자님께서 저희에게 물어볼 것이나 덧붙이고 싶은 말이 있다면 간단히 말씀해 주세요.
